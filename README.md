# 어떳헤어또케 공부?;; 🤑

가장 중요한 부분입니다. 말로는 해적왕 대통령 트럼프 다 할 수 있는 것을 누구보다 압니다.

## 방안

1. 청사진 파악
   각 자료구조의 이름의 의미와 카테고리를 정리하고 쓰임새를 정리해서 전체적인 구조와 관계를 정리했습니다.

```
자료구조
    배열, 스택, 큐, 해시, 힙/우선순위 큐, 트리
탐색
    DFS/BFS, 이진탐색, 백트래킹
배열놀기
    투 포인터, 슬라이딩 윈도우, 누적합
최적화
    그리디, DP
그래프
    다익스트라, 유니온 파인드, 위상정렬, MST
```

2. 예시코드
   가장 스텐다드, 기본이 되는 덜어낸 코드를 쓰고 근본을 파악합니다

3. 오답노트
   예시 코드를 기반으로 응용을 하고, 그 과정에서 어려운 것을 정리합니다

4. 저급한 필기
   효율적 공부를 위해서 최선을 다합니다.
